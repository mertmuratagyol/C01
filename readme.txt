42 C Piscine - C01

This repository contains my solutions for the C01 project of the 42 Kocaeli C Piscine.

About the Project

The C01 project dives deeper into pointer manipulation, memory addresses, and basic array handling in C. It reinforces core concepts of passing parameters by reference, pointer arithmetic, and algorithmic logic under the strict constraints of the 42 Norm.

Exercises

* Ex00: Stores a number inside a variable pointed to by a pointer (ft_ft.c)
* Ex01: Takes a pointer to a pointer to a pointer... and sets the value (ft_ultimate_ft.c)
* Ex02: Swaps the values of two integers given via pointers (ft_swap.c)
* Ex03: Divides parameters and stores the result and remainder (ft_div_mod.c)
* Ex04: Accumulates division and modulo operations (ft_ultimate_div_mod.c)
* Ex05: Displays a string through a pointer (ft_putstr.c)
* Ex06: Counts and returns the length of a string (ft_strlen.c)
* Ex07: Reverses a given array of integers in place (ft_rev_int_tab.c)
* Ex08: Sorts an array of integers in ascending order (ft_sort_int_tab.c)

Technologies & Rules

* Language: C
* Compiler: gcc (with -Wall -Wextra -Werror flags)
* Standard: 42 Norm (Norminette compliant)
